# Security Policy

## Supported Versions

Currently, only the latest version of the CGPA Calculator on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Security is a top priority. If you discover a security vulnerability within this project, please do not disclose it publicly.

Instead, please report it via one of the following methods:
1. Open a private security advisory on GitHub (if enabled for the repository).
2. Email the maintainer directly (if an email is provided on the profile).

We will triage the vulnerability and respond as quickly as possible, usually within 48 hours. If the vulnerability is confirmed, we will release a patch as soon as possible.

Thank you for helping keep this project secure!
